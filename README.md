## Реализация функций сортировки и фильтрации

### Описание:

#### Функция сортировки *sort_by_date()*

`def sort_by_date(list_of_dicts: list, order: bool = True) -> list:`

Функция принимает список словарей и необязательный параметр, задающий порядок сортировки (по умолчанию — убывание) и
возвращает новый список, отсортированный по дате.

#### Функция фильтрации *filter_by_state()*

`def filter_by_state(list_of_dicts: list, state: str = "EXECUTED") -> list:`

Функция принимает список словарей и возвращает новый список словарей, содержащий только те словари, у которых ключ state
соответствует указанному значению

### Установка:

* Ничего устанавливать не надо
* Для проверки роботы функции нужно раскомментировать закомментированный текст
